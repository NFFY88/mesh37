# Что такое ноды

Нода (от англ. node - узел) - это базовый элемент любой mesh-сети: устройство, которое принимает, обрабатывает и передаёт сообщения другим участникам сети. 
В контексте Meshtastic и MeshCore нодой называют любое LoRa-устройство, подключённое к общей децентрализованной сети.

## Как работает нода?

- Получает сообщение по радиоканалу (LoRa)
- Обрабатывает его и, при необходимости, передаёт дальше (ретранслирует)
- Обменивается данными с телефоном/ПК через Bluetooth, Wi-Fi или USB
- Может передавать телеметрию: координаты, заряд батареи, данные с датчиков

:::tip[Важно]
Чем больше активных нод в сети - тем устойчивее и дальнобойнее становится вся сеть. Каждая новая нода усиливает покрытие и надёжность связи для всех участников.
:::
