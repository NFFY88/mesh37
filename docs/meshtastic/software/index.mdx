# Программное обеспечение для Meshtastic

В этом разделе собрана информация о программном обеспечении для управления вашими Meshtastic-устройствами, обмена сообщениями и мониторинга сети.

## Официальные клиенты для Meshtastic

В зависимости от платформы, которую вы используете, есть несколько вариантов клиентов для управления вашими Meshtastic-устройствами и обмена сообщениями. 
Ниже представлены основные официальные клиенты для Android, iOS и веб-браузера.

### Android

Приложение для Android позволяет настраивать ноды, отправлять и получать сообщения, просматривать карту с GPS-координатами и телеметрией. Вы можете скачать его тремя способами:

- **Google Play**: https://play.google.com/store/apps/details?id=com.geeksville.mesh
- **F-Droid**: https://f-droid.org/packages/com.geeksville.mesh/
- **GitHub**: https://github.com/meshtastic/Meshtastic-Android

#### В чем разница между версиями?

- **Google Play**: самая простая установка и автоматические обновления, но может содержать проприетарные компоненты (к примеру, Google Services).
- **F-Droid**: полностью открытый исходный код, без проприетарных зависимостей, но обновления могут выходить с задержкой.
- **GitHub**: исходный код для самостоятельной сборки, подходит для разработчиков и энтузиастов, которые хотят внести изменения или использовать кастомные сборки. 
Также оттуда можно скачать готовые APK-файлы для ручной установки.

### iOS

Приложение для iOS также поддерживает все основные функции: настройка нод, обмен сообщениями, отображение GPS-координат и телеметрии. 
Вы можете скачать его из App Store: https://apps.apple.com/us/app/meshtastic/id1586432531


### Web Client

**Meshtastic Web** - это веб-клиент Meshtastic, работающий непосредственно в вашем браузере. Доступ к приложению возможен двумя способами:

1. Непосредственно в браузере по адресу: https://client.meshtastic.org/
2. Локально, скачав и запустив его на своём компьютере. Исходный код доступен на GitHub: https://github.com/meshtastic/web

Приложение будет работать во всех основных браузерах, но в некоторых случаях его функциональность будет ограничена. 
Рекомендуется использовать браузер на основе Chromium, например, Google Chrome или Microsoft Edge.

## Клиенты от сторонних разработчиков

### MeshMonitor

**MeshMonitor** - это desktop-клиент для мониторинга и управления Meshtastic-устройствами. Он предоставляет расширенные функции визуализации сети, 
отображения топологии и анализа производительности.

![MeshMonitor](/img/meshtastic/software/meshmonitor.jpg)

Основные функции MeshMonitor:
- Визуализация сети в реальном времени
- Мониторинг состояния нод и связи между ними
- Поддержка различных типов устройств и протоколов связи
- Удобный интерфейс для настройки и управления нодами
- Автоматизация работы с помощью скриптов и API

Узнать больше и скачать можно по ссылке: https://meshmonitor.org/


### MeshApp
**MeshApp** - полнофункциональный кроссплатформенный десктопный клиент для Meshtastic, работающий по TCP, Serial / USB и BLE. 

Основные функции MeshApp:
- Поддержка всех основных платформ: Windows, macOS и Linux
- Чаты и обмен сообщениями
- Работа с узлами сети: поиск, сортировка, фильтрация
- Телеметрия и мониторинг

Узнать больше и скачать можно по ссылке: https://meshapp.ru/

## Разработки участников сообщества

### Meshtastic TUI Messenger

Минималистичный терминальный (TUI) мессенджер для работы с автономными радиосетями Meshtastic, написанный на Python с использованием фреймворка Textual. Поддерживает живой мониторинг эфира и приватные чаты.

![Meshtastic TUI Messenger](/img/meshtastic/software/meshtastic-tui-messenger.jpg)

Подробности и исходный код: https://github.com/mikeelucky/meshtasticCLI
