# Настройки радиомодуля

В этом разделе рассмотрим основные настройки радиомодуля в ноде Meshtastic. Здесь вы узнаете, как выбрать частоту, настроить мощность передачи, выбрать канал связи и другие параметры, которые влияют на дальность и стабильность связи в вашей сети. Правильная настройка радиомодуля поможет оптимизировать работу сети и обеспечить надёжную связь между устройствами.
