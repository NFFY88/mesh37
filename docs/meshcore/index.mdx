# Meshcore

В данный момент сеть Meshcore в Иванове слабо развита и имеет небольшое покрытие. Если вам интересно, можете попробовать поучаствовать в ее развитии.

##  Настройки сети Meshcore - Иваново

Для подключения к нашей локальной сети введите эти параметры в настройках радиомодуля (раздел LoRa). 

- Частота (МГц): 868.731018
- Полоса пропускания (кГц): 62.5
- Spreading Factor (SF): 8
- Coding Rate (CR): 8

:::warning[Важно]

После ввода данных не забудьте сохранить изменения и перезагрузить плату!

:::
