# Reticulum

Reticulum - это сетевой протокол и криптографический стек, который позволяет создавать децентрализованные сети без необходимости в центральных серверах. Он обеспечивает безопасную и приватную связь между устройствами, используя уникальные идентификаторы и шифрование. Он позволяет развернуть сеть поверх чего угодно, будь то Wi-Fi, Bluetooth, LoRa или даже через интернет. Reticulum может быть использован для создания локальных сетей, а также для связи между различными сетями.
